| Element | Primary Tactical Effect | Synergistic Weapon Example | Ideal Team Role |

## 5. Tactical Run Guide: Surviving the Swarm Modes

To consistently conquer 15-minute runs, players should follow a structured tactical playbook:

```
+-------------------------------------------------------------------------+
|                  TACTICAL STEP-BY-STEP PLAYBOOK                         |
|                                                                         |
|  1. Prioritize Objectives  -->  2. Balance Squad Elements               |
|     (Secure Solar Panels)          (1 Crowd Control + 2 DPS)            |
|                                                                         |
|  3. Maintain Spacing       -->  4. Bank Honor Points                    |
|     (Avoid Swarm Traps)            (Invest in Cooldown & Speed)         |
+-------------------------------------------------------------------------+
```

1. **Prioritize Timed Quests:** Complete map events like building solar panels early. The capsules awarded provide game-changing stat boosts.
2. **Diversify Elemental Coverage:** Avoid stacking only one damage type. Pairing Ice (for crowd control) with Lightning and Fire ensures you can handle both giant swarms and armored elite bugs.
3. **Control Choke Points:** Use solarpunk environmental hazards and persistent area-denial skills (like Poison ground effects) to channel insect swarms into tight kill zones.
