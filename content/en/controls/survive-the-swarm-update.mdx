## Control Layouts and Input Optimization

Navigating a dense bullet-hell roguelite demands pinpoint accuracy. *Survive the Swarm* combines traditional twin-stick movement with strategic squad coordination, making button responsiveness essential during chaotic 15-minute runs.

### Default Gamepad and Keyboard Mappings

Whether you prefer playing on a traditional gamepad or a mouse and keyboard, configuring your controls ensures rapid reaction times during sudden Swarm and Boss events.

| Action | Gamepad (Xbox / Steam Deck) | Keyboard & Mouse (Default) | Tactical Purpose |
| :--- | :--- | :--- | :--- |
| **Squad Movement** | Left Stick | `W`, `A`, `S`, `D` | Positioning and kiting enemy swarms |
| **Aiming / Direction** | Right Stick | Mouse Cursor | Directing projectile salvos and directional abilities |
| **Dash / Evasion** | `A` / `Cross` | `Spacebar` | Dodging heavy boss telegraphs and clearing encirclements |
| **Primary Skill Trigger** | `Right Trigger (RT)` | `Left Mouse Button (LMB)` | Firing primary exterminator weapon |
| **Squad Skill / Ability**| `Left Trigger (LT)` / `X` | `Right Mouse Button (RMB)` / `E` | Activating secondary elemental skills |
| **Mid-Run Recruit / Interact** | `Y` / `Triangle` | `F` | Interacting with recruit pods and quest objectives |
| **Pause / Stats Screen** | `Start` / `Options` | `Escape` / `Tab` | Checking build statistics and elemental synergies |

### Menu Navigation and Hotfix Tweaks

Recent patches specifically addressed interface flow. In the latest patch cycles, developers modified menu navigation to eliminate dead-ends when using controllers. Moving directional inputs left or right on key overlay menus now directs players straight to functional buttons like "Exit Game" or "Confirm," preventing control lockouts when navigating outside the active arena.

## Frequently Asked Questions (FAQ)

### What major improvements arrived with the latest Survive The Swarm update?
The latest updates brought Steam Deck performance optimizations targeting 60 FPS, fixed weapon stat card descriptions (such as the Mitosic Arrow critical chance fix), repaired the "Upstanding Citizen" achievement, and refined controller menu mapping for smoother navigation.

### How do I configure gamepad controls for Survive the Swarm on Steam Deck?
The default gamepad layout functions automatically out of the box. However, for specific screens like Achievements that are still receiving UI patches, you can temporarily utilize the Steam Deck's right trackpad as a mouse cursor or tap the touchscreen directly to navigate.

### What should I do if Kia's Photopsia ability causes lag or freezing?
Based on player experience and community reports, excessive clone generation with Photopsia can cause performance drops. If you encounter lag, reduce duplicate clone upgrades during that run while awaiting an official performance patch.

### How does meta-progression work in Survive the Swarm?
Regardless of whether you finish a run, you earn Honor Points based on enemies defeated and objectives completed. These points are spent in the main menu to purchase permanent squad-wide upgrades, including movement speed, damage bonuses, and reduced cooldowns.
