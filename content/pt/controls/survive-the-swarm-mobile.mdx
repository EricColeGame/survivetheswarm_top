## Entendendo o Esquema Básico de Controles

*Survive the Swarm* combina mecânicas de ataque automático típicas do gênero survivors-like com o gerenciamento ativo de esquadrão. Ao contrário dos tradicionais bullet heavens de personagem único, aqui você comanda uma formação com múltiplos exterminadores solarpunk, tornando o direcionamento, as esquivas e a mira de habilidades fatores essenciais.

Quer você esteja configurando direcionais analógicos virtuais ou jogando em controles portáteis dedicados, dominar o layout básico é fundamental.

| Categoria de Ação | Comando Principal (Controle / Portátil) | Interface de Toque / Remota | Função Estratégica |
| :--- | :--- | :--- | :--- |
| **Movimentação** | Analógico Esquerdo | Joystick Virtual Esquerdo | Direciona o posicionamento do esquadrão e as rotas de kiting |
| **Esquiva / Dash** | Botão Sul (A / Cruz) | Botão de Toque Rápido Inferior Direito | Desvia de investidas do enxame e de zonas de perigo |
| **Habilidade Ativa** | Gatilho Direito (RT / R2) ou (X / Quadrado) | Seletor de Habilidades Direito | Aciona poderes específicos de unidades com tempo de recarga |
| **Interagir / Recrutar** | Botão Oeste (X / Quadrado) | Ícone Contextual Pop-up | Captura nós solares, coleta itens e recruta membros para o esquadrão |
| **Pausa Tática / Mapa** | Botão Menu / Start | Ícone de Engrenagem / Mapa Superior Direito | Pausa temporizadores de eventos e exibe as passivas ativas |

## Otimizando os Controles de Survive The Swarm em Portáteis e no Steam Deck

Para jogadores que utilizam hardware portátil, os desenvolvedores implementaram suporte nativo com o objetivo de manter uma taxa estável de 60 FPS. Embora o título seja voltado para controles tradicionais, jogar em telas menores apresenta desafios visuais e operacionais específicos.

De acordo com atualizações oficiais dos desenvolvedores no [Survive the Swarm Steam Community Hub](https://steamcommunity.com/app/2977700), as otimizações para portáteis continuam aprimorando a legibilidade em telas compactas. Ao configurar seu dispositivo portátil ou jogar uma versão transmitida de **Survive The Swarm mobile**, aplicar zonas mortas (deadzones) personalizadas e botões traseiros aumenta drasticamente a sua capacidade de sobrevivência.

### Mapeamento Recomendado para Portáteis e Controles

| Botão / Gatilho | Remapeamento Recomendado | Utilidade no Jogo |
| :--- | :--- | :--- |
| **Analógico Esquerdo** | Zona Morta Radial Padrão (10%) | Kiting direcional preciso em 360 graus |
| **Analógico Direito** | Direção da Mira (Twin-Stick Opcional) | Mira habilidades direcionais (ex.: Arco da Blaze) |
| **L4 / L5 (Grips Traseiros)** | Esquiva / Interação | Mantém os polegares fixos nos analógicos o tempo todo |
| **R4 / R5 (Grips Traseiros)** | Ativação de Habilidade Primária | Evita o atraso de tirar o polegar do analógico em lutas contra chefes |
| **Trackpad Direito (Deck)** | Como Ponteiro do Mouse | Navegação rápida pelos menus de meta-progressão pós-onda |

### Ajustes de Interface e Exibição em Portáteis

Telas pequenas podem dificultar a visualização de elementos minuciosos da interface durante grandes ondas de monstros. Siga estas etapas para otimizar sua experiência portátil:

1. **Escala de Texto e Densidade do HUD**: Aumente a escala da interface quando disponível para evitar fadiga visual durante partidas rápidas de 15 minutos.
2. **Curvas de Resposta do Analógico**: Mude para uma curva **Agressiva** ou **Linear** para reposicionar seu esquadrão instantaneamente quando emboscadas do enxame surgirem.
3. **Alternativa para Navegação em Menus**: Relatos da comunidade indicam que certas abas de menu (como conquistas) ocasionalmente exigem comandos por toque ou emulação de trackpad até que futuras atualizações tragam total paridade de controle.

## Controles de Toque e Layouts para Streaming Mobile

Se você transmite o jogo via Steam Link, Moonlight ou aplicativos no estilo Xbox Cloud para jogar **Survive The Swarm mobile** em aparelhos iOS ou Android, uma interface padrão de botões virtuais pode poluir sua tela. Como as hordas de insetos atacam em 360 graus, o espaço útil de tela é indispensável.

```
+-------------------------------------------------------------+
| [Pausa/Honra]                                  [Mini-Mapa]  |
|                                                             |
|                                                             |
|     (Polegar Esquerdo)              (Polegar Direito)       |
|    [Joystick Flutuante]            [Dash]     [Interagir]   |
|                                                             |
|                                      [Habilidade Ativa]     |
+-------------------------------------------------------------+
```

### Configurações Essenciais para Jogabilidade Touch

* **Joystick Flutuante Dinâmico**: Habilite o direcional flutuante para que o centro de movimentação se fixe exatamente onde o seu polegar esquerdo tocar na tela.
* **Espaçamento e Opacidade dos Botões**: Reduza a opacidade da sobreposição de toque para 35–40% a fim de manter visíveis os grupos de insetos nos cantos inferiores.
* **Confirmação Tátil (Haptic Feedback)**: Ative a vibração de toque para confirmar o uso do dash sem precisar olhar diretamente para os botões.

## Controles de Esquadrão: Elementos, Sinergias e Gerenciamento de Habilidades

O sucesso em *Survive the Swarm* depende fortemente de gerenciar seu elenco de 12 personagens distintos, divididos em quatro alinhamentos elementais primários. As suas ações determinam não apenas o comportamento do seu líder, mas também a eficácia com que todo o esquadrão ativa combos elementais.

| Elemento | Mecânica Central | Melhor Estilo de Comando | Exemplo de Herói Recomendado |
| :--- | :--- | :--- | :--- |
| **Fogo** | Dano Contínuo (DoT) e Clivagem de Área | Movimentos em arco amplo / Controle de zona | Blaze (Arco Longo de Precisão) |
| **Gelo** | Controle de Grupo e Congelamento | Mira direcional em pontos de afunilamento | Unidades Tank Defensivas |
| **Raio** | Rajada em Cadeia e Ciclo Rápido | Toques de alta frequência | Especialistas em Choque Rápido |
| **Veneno** | Negação de Área e Redução de Armadura | Kiting perimetral e táticas de bater e correr | Isla (Martelo Devastador) |

### Equilibrando as Habilidades do Esquadrão

Ao montar sua equipe durante uma partida, equilibrar ações manuais com causadores de dano passivo é vital para fases de alta dificuldade:

1. **Misture Exterminadores Ativos e Passivos**: Não sobrecarregue seu esquadrão com heróis que exigem alinhamento manual de alvos. Combine atiradores direcionais como Blaze com unidades de aura autônoma como Isla.
2. **Atenção aos Gargalos de Desempenho**: Experiências compartilhadas pela comunidade destacam que habilidades com muitos clones (como a Photopsia de Kia) podem gerar um volume massivo de partículas. Reduza os efeitos visuais caso perceba quedas de quadros em sessões de streaming mobile.
3. **Cumpra os Eventos Temporizados com Eficiência**: Durante o ciclo de 15 minutos da partida, priorize mover-se imediatamente em direção às cápsulas de Recrutamento e Missão assim que os temporizadores surgirem no HUD.

## Otimizando a Meta-Progressão e o Uso de Pontos de Honra

Cada partida em **Survive The Swarm mobile** e em formatos portáteis recompensa você com Pontos de Honra, ganhe ou perca. Gastar esses pontos com sabedoria na árvore permanente de meta-progressão compensa diretamente as limitações de controle em telas menores, oferecendo margens de segurança mais amplas.

| Meta-Aprimoramento | Prioridade de Custo de Honra | Benefício Tático para Jogadores Mobile/Portátil |
| :--- | :--- | :--- |
| **Velocidade de Movimento** | Alta (Tier 1) | Amplia a margem de manobra no kiting contra unidades rastejantes velozes |
| **Redução do Tempo de Recarga do Dash** | Altíssima (Tier 1) | Concede mais quadros de invulnerabilidade frequentes durante fugas |
| **Área de Efeito Global (AoE)** | Alta (Tier 2) | Reduz a necessidade de micro-mira em interfaces de toque |
| **Regeneração de Vida do Esquadrão** | Média (Tier 2) | Amortece o dano acidental sofrido por pontos cegos em telas menores |
| **Multiplicador de Pontos de Honra** | Média (Tier 3) | Acelera a progressão geral da conta para todos os personagens |

## Solução de Problemas: Controles e Configurações de Desempenho

Para garantir um desempenho constante a 60 FPS durante os picos de densidade da horda em seus dispositivos portáteis, utilize a lista de verificação abaixo:

| Problema / Sintoma | Causa Provável | Solução Recomendada |
| :--- | :--- | :--- |
| **Atraso de Entrada (Input Lag) / Ghosting** | Oscilação na taxa de bits do streaming | Reduza a resolução de transmissão para 1080p/720p; configure a sincronização para baixa latência. |
| **Deriva do Analógico (Drift) em Ondas** | Calibração de zona morta muito baixa | Aumente a zona morta do analógico para 12–15% nas configurações de controle. |
| **Quedas de FPS com Clones/Spawns** | Excesso de partículas de efeitos visuais (VFX) | Reduza o tremor de tela (screen shake) e configure a densidade de partículas para Média. |
| **Comandos de Interação Não Respondem** | Sobreposição de botões na interface | Remapeie a tecla de interagir para longe do botão principal de dash para evitar toques acidentais. |

## Perguntas Frequentes (FAQ)

### Existe um aplicativo móvel nativo oficial de Survive The Swarm para iOS ou Android?
Até as atualizações de desenvolvimento atuais, o jogo é produzido primariamente para PC, com otimizações ativas para sistemas portáteis como o Steam Deck. No entanto, você pode aproveitar perfeitamente uma experiência de **Survive The Swarm mobile** hoje mesmo transmitindo o jogo do seu PC para o celular ou tablet através de aplicativos de jogo remoto como Steam Link, Moonlight ou AMD Link.

### Como corrigir textos pequenos no jogo ao jogar em dispositivos portáteis?
A equipe de desenvolvimento reconheceu a questão da escala de texto em portáteis nas notas de atualização da comunidade e está implementando melhorias de interface continuamente. Enquanto isso, você pode usar os recursos integrados de zoom do sistema (como o atalho `Botão Steam + L1` no Steam Deck) para inspecionar rapidamente os atributos das armas.

### Posso jogar Survive The Swarm com um controle Bluetooth no celular?
Sim. Se estiver utilizando streaming remoto para jogar **Survive The Swarm mobile**, parear um controle Bluetooth externo (como um controle sem fio de Xbox, PlayStation DualSense ou controles de encaixe para celular) oferece compatibilidade plug-and-play completa, garantindo movimentação analógica precisa e gatilhos dedicados para esquivas.
