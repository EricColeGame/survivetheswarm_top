## 1. Kern-Spielmodi und die Struktur der 15-Minuten-Runs

Im Gegensatz zu traditionellen, auf Einzelfiguren fokussierten Horde-Survival-Spielen setzt *Survive the Swarm* auf taktisches Team-Management innerhalb eines fest gesteckten Zeitfensters. Jede Standardexpedition dauert exakt 15 Minuten und erfordert schnelle Entscheidungsfindung sowie flexible Anpassungsfähigkeit.

```
+-------------------------------------------------------------------+
|                  LEBENSZYKLUS EINES 15-MINUTEN-RUNS               |
|                                                                   |
|  [0:00 - 4:00]   -->  [4:00 - 8:00]   -->  [8:00 - 15:00]         |
|  Initialer Spawn      Rekrutierung &       Schwarm- & Boss-Kämpfe |
|  & Quest-Events       Squad-Synergie       Ehrenpunkte-Extraktion |
+-------------------------------------------------------------------+
```

Während dieses 15-minütigen Überlebensmodus wechselt das Schlachtfeld zwischen strukturierten Missionszielen und chaotischen Bullet-Hell-Wellen:

| Run-Phase | Dauer / Auslöser | Hauptziel | Wichtigste Belohnungen & Gefahren |
| :--- | :--- | :--- | :--- |
| **Quest-Phase** | Früher Run (Minuten 0–4) | Karten-Herausforderungen abschließen (z. B. Solarpaneele bauen) | Squad-Buffs, Belohnungskapseln, Elite-Insekten-Spawns |
| **Rekrutierungsphase**| Mittlerer Run (Minuten 4–8) | Neue Squad-Mitglieder entdecken und retten | Größere Gruppenstärke, neue Elementarkombos |
| **Schwarm-Phase** | Später Run (Minuten 8–13) | Dichte, bildschirmfüllende Käferwellen überleben | Riesige XP-Kristalle, hohe Gefahr eines Squad-Wipes |
| **Boss-Phase** | Finale (Minuten 13–15) | Den Apex-Insektentyrannen besiegen | Run-Abschluss, Bonus-Ehrenpunkte |

## 2. Squad-Building und Analyse der Elementarsynergien

Ein zentrales Highlight der ersten Vorschauen und Gameplay-Enthüllungen ist die Squad-Dynamik. Sie steuern nicht nur einen einzelnen Helden, sondern rekrutieren und befehligen ein Einsatzteam aus einer Auswahl von 12 individuellen Solarpunk-Kämpfern.

Jeder Exterminator nutzt einen spezifischen Waffenstil und eine Elementaraffinität. Das Kombinieren dieser Elemente löst mitten im Run mächtige Statuseffekte aus:

| Element | Primärer taktischer Effekt | Beispiel für Synergiewaffe | Ideale Teamrolle |
| :--- | :--- | :--- | :--- |
| **Feuer** | Hoher Schaden über Zeit (Verbrennung) | Präzisions-Langbogen (z. B. Blaze) | Schnelles Ausschalten von Elite-Einzeltargets |
| **Eis** | Massenverlangsamung & einfrierendes Zerspringen | Flächenwirkungs-Tools zur Massenkontrolle | Lane-Kontrolle und defensive Raumdeckung |
| **Blitz** | Kettenschaden auf nahestehende Insekten | Hochgeschwindigkeits-Projektilwerfer | Schwarmbeseitigung und Wellenunterdrückung |
| **Gift** | Rüstungskorrosion & anhaltende Schadenszonen | Zerschmetternder Hammer (z. B. Isla) | Raumverweigerung und Ziele mit hoher Haltbarkeit |

### Squad-Entwicklung während des Runs

Sammeln die Exterminatoren im Kampf Erfahrung, schalten sie spezialisierte Fähigkeiten frei. Helden wie Kia bieten beispielsweise unverwechselbare offensive Werkzeuge wie Photopsia – frühe Demo-Erfahrungen zeigten jedoch, dass die Dichte von Fähigkeitsklonen aktive Balance-Patches erforderte, um eine klare visuelle Übersicht zu gewährleisten.

## 3. Persistente Progression: Die Ehrenpunkte-Ökonomie

Ein Scheitern ist schlicht Teil des taktischen Kreislaufs. Selbst wenn Ihr Squad fällt, bevor der finale Boss erscheint, gewährt jeder Run **Ehrenpunkte**. Diese Punkte finanzieren permanente Meta-Upgrades, die Ihr gesamtes Roster für nachfolgende Expeditionen verstärken.

| Upgrade-Knoten | Effekt pro Rang | Taktischer Nutzen | Prioritätsstufe |
| :--- | :--- | :--- | :--- |
| **Squad-Vitalität** | +5% Maximale Gesundheit für alle Einheiten | Erhöht die Überlebenschancen bei chaotischen Schwarmspitzen | Hoch |
| **Übertaktungs-Tech** | -4% Globale Abklingzeiten für Fähigkeiten | Schnellere Auslösung von Fähigkeiten zur Massenkontrolle | Kritisch |
| **Thermischer Schub** | +6% Schaden durch Elementareffekte | Verstärkt die Skalierung von Feuer, Eis, Gift und Blitz | Mittel |
| **Kinetische Triebwerke** | +3% Basis-Bewegungs- & Dash-Geschwindigkeit | Erleichtert das Neupositionieren gegen aggressive Schwarm-Eliten | Hoch |
| **Ehren-Multiplikator**| +5% Bonus-Ehrenpunkte pro Run | Beschleunigt die langfristige Meta-Progression | Pflicht für das Early Game |

## 5. Taktischer Run-Leitfaden: Das Meistern der Schwarm-Modi

Um 15-Minuten-Runs beständig erfolgreich abzuschließen, sollten Spieler einem strukturierten taktischen Ablaufplan folgen:

```
+-------------------------------------------------------------------------+
|                  STRATEGISCHER SCHRITT-FÜR-SCHRITT-LEITFADEN             |
|                                                                         |
|  1. Missionsziele fokussieren  -->  2. Squad-Elemente ausbalancieren    |
|     (Solarpaneele sichern)             (1 Crowd Control + 2 DPS)        |
|                                                                         |
|  3. Abstand wahren             -->  4. Ehrenpunkte sichern              |
|     (Schwarmfallen meiden)             (In Cooldown & Speed investieren)|
+-------------------------------------------------------------------------+
```

1. **Zeitgesteuerte Quests priorisieren:** Schließen Sie Kartenevents wie das Errichten von Solarpaneelen frühzeitig ab. Die erhaltenen Kapseln liefern spielentscheidende Status-Boosts.
2. **Elementarabdeckung diversifizieren:** Vermeiden Sie es, sich nur auf einen Schadenstyp zu verlassen. Die Kombination von Eis (zur Massenkontrolle) mit Blitz und Feuer stellt sicher, dass Sie sowohl riesige Schwärme als auch gepanzerte Elite-Käfer bewältigen können.
3. **Engpässe kontrollieren:** Nutzen Sie Umweltgefahren der Solarpunk-Welt und langanhaltende Fähigkeiten zur Raumkontrolle (wie Giftzonen am Boden), um Insektenschwärme in enge Todeszonen zu leiten.

### Was macht die im Survive The Swarm Launch-Trailer gezeigten Kämpfe so einzigartig?
Das Spiel kombiniert das automatisierte Angriffsformat von Schwarm-Survival-Spielen mit aktiver taktischer Truppenführung. Anstatt eine einzelne Spielfigur zu steuern, stellen Sie ein Team aus bis zu 12 Solarpunk-Kammerjägern zusammen und verbessern es mithilfe ineinandergreifender Elementarsynergien.

### Wie lange dauert ein Standard-Run?
Jeder Standard-Run-Modus dauert exakt 15 Minuten und umfasst zeitgesteuerte Quest-Phasen, Rekrutierungsgelegenheiten sowie finale Boss-Showdowns.

### Kann ich Survive the Swarm auf dem Steam Deck spielen?
Ja. Offizielle Entwickler-Updates bestätigen, dass das Spiel auf dem Steam Deck flüssig mit 60 FPS läuft. Derzeit werden kontinuierlich UI-Optimierungen vorgenommen, um die Textlesbarkeit und Gamepad-Navigation für eine vollständige Handheld-Verifizierung zu perfektionieren.
