### Warum funktioniert mein Code nicht?

Wenn du versuchst, eine Belohnung einzufordern, und eine Fehlermeldung erhältst, überprüfe diese häufigen Fehlerquellen:

* **Groß-/Kleinschreibung:** Roblox-Eingabefelder unterscheiden Groß- und Kleinschreibung. "CLASSES" funktioniert, "classes" hingegen nicht.
* **Leerzeichen am Ende:** Beim Kopieren und Einfügen von Codes aus sozialen Medien kann versehentlich ein Leerzeichen am Ende hinzugefügt werden.
* **Einmalige Nutzung:** Jeder Aktionscode kann pro Roblox-Konto nur ein einziges Mal eingelöst werden.
* **Serverversion:** Nach einem neuen Update erkennen ältere Server den neuesten Code möglicherweise nicht sofort. Ein Rejoin auf einen frischen Server behebt dies oft.
